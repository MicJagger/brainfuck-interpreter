# brainfuck-interpreter

C-interpreter to run brainfuck code

# Installation

1. ``git clone LINK``
2. ``cd brainfuck-interpreter``

``make`` to build the executable

``make run`` to build and run

``make hello-world`` to build and run ``./examples/helloworld.bf``

# Usage

There are two options:

1. Run with no arguments (such as through the makefile), which will then ask you to input a file name
2. Run with one argument being the file name
